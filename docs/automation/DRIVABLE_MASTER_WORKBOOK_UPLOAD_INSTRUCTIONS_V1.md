# Drivable Master Operations Workbook V1 Upload Instructions

1. Open Google Drive.
2. Upload `Drivable_Master_Operations_Workbook_V1.xlsx`.
3. Open the uploaded file with Google Sheets.
4. Use **File > Save as Google Sheets** if Google does not automatically convert it.
5. Rename the Google Sheets version to **Drivable Master Operations Workbook V1**.
6. Use this Google Sheets workbook for all Make scenarios going forward.

## Important

- Do not manually rename headers after Make scenarios are mapped.
- Make depends on the exact Row 1 header names.
- Keep the Excel file as a backup/export copy.
- Do not add decorative rows above Row 1.
- Do not merge cells in managed tabs.
